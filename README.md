# Tělo

Pavol's body scoreboard: four tracked metrics (wall-test gap, wall angels,
hollow hold, daily energy) with goals, trends, and monthly posture photos.
Mobile-first, Czech UI. See `AGENTS.md` for build/test commands.

## Legacy

`legacy/gLocHistory.py` — a 2014 Python 2 script that converted Google
Location History JSON exports into the Zenobase import format. Superseded,
kept for reference only; not part of the Tělo app.
